# MG Shop - Aqua Mulhouse

Dans le cadre de mon alternance chez Logitud, j'ai participé à la refonte du tunnel d'achat et des interfaces d'administration pour les piscines de Mulhouse (Aqua Mulhouse).

## Fonctionnalités Clés

- **Tableaux de données (DataTables) :**
  Développement de composants avancés de tableaux de données intégrant recherche, tri, sélecteur de colonnes, persistance d'état et export (CSV / PDF).
- **Composants d'interface (UI) :**
  Mise en place de tiroirs (drawers) superposables, d'une palette de commandes avancée (CommandPalette) et d'un comparateur de code (GitDiff).
- **Processus de paiement :**
  Création d'un tunnel d'achat et d'un système de panier générique, réutilisable et paramétrable via l'interface d'administration.
- **Qualité de code :**
  Automatisation des vérifications sur chaque pull request grâce à des workflows GitHub Actions incluant le linting et les tests unitaires sous Vitest.
