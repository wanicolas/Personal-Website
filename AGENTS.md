# Personal website - Guide pour Agents IA

For essential informations, read the [README](./README.md).

## Stack Technique

- **Framework**: Nuxt 4 (Vue 3 + TypeScript)
- **Styling**: TailwindCSS
- **Traductions**: Nuxt I18n
- **SEO**: Nuxt SEO
- **Package Manager**: pnpm

## Nuxt distinctive features

### Auto-imports

- **Vue**: `ref`, `computed`, `watch`, etc.
- **Composables**: `useState`, `useRouter`, `useFetch`, etc.
- **Composants**: Named after their path in `components/`
- **Stores**: `usePinia`, `defineStore`, `storeToRefs`, `acceptHMRUpdate`, `use*Store` from `stores/`
- **Utils**: From `utils/`
